If you open an app to check the Moon phase, you should be able to tell which part was calculated and which part comes from a tradition. Astro Worker is an app for Sisters with Mirrors that keeps those distinctions visible across astronomy, astrology, numerology, and spiritual content.

It’s built to work offline. The web app can be installed in a supported browser, and the source is available for anyone who wants to see how it works or build it themselves.

## Project updates

**27 November 2026.** Platform checks have passed for Android, macOS, Windows, and the web. The browser tests also covered opening a cached build with the server unavailable. Signed distribution and widget behaviour on physical devices have their own checks before release.

Astro Worker is built by [RePass Cloud](https://repasscloud.com/) for Sisters with Mirrors.
