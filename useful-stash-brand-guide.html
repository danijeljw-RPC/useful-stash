05 · Cover generator

SVG first. PNG for YouTube.

The bundled shell script accepts repeated tags, `^...^` highlight markers, a subtitle, and a geometric shape. It generates the reusable SVG and converts it to 1280×720 PNG.

./generate-youtube-cover.sh \
  --tag=DOCKER \
  --tag=.NET \
  --title="your docker image is ^too big.^" \
  --subtitle="2.1GB ^→^ 482MB" \
  --shape=hexagon \
  --output=cover-docker-size
ArgumentMeaning
--tag=...Repeatable. Renders `[ TAG ]` in Soft Orange.
--title=...Required. Automatically uppercased. Text inside paired `^` markers uses Useful Orange.
--subtitle=...Optional. Supports the same `^...^` highlighting.
--shape=...circle, square, diamond, hexagon, or none.
--output=...Output basename. Creates `.svg` and `.png`.
--no-pngKeep only the SVG source.

Recommended on macOS: brew install librsvg. The script also falls back to ImageMagick or Inkscape.

08 · Design boundaries

Technical without developer cosplay.

Do

Use real screenshots, diagrams, code where relevant, strong typography, warm editorial spacing, concise labels and practical language.

Don't

Use `>_` as the identity, Matrix backgrounds, neon hacker graphics, generic SaaS gradients, stock laptops or glowing code as decorative filler.
